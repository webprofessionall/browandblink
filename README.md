# Browandblink by Mikela Varrosi

Website for Browandblink, a brows, lashes and beauty studio on Clifton Road, Grimsby.

## What's on the site
- Services: brows, lashes, waxing, permanent makeup and facials
- "Our work" photo gallery
- Booking enquiry form that sends straight to the studio's email
- Links to Instagram: [@browandblinkk](https://www.instagram.com/browandblinkk)

## Files
- `index.html`: the whole site in one file (HTML, CSS, JavaScript and photos included)

## Booking form
The form sends enquiries to Mikelavarrosi@yahoo.com using [FormSubmit](https://formsubmit.co).
After the site goes live, send one test enquiry and activate it from the email
FormSubmit sends to the studio. Until then, enquiries are not delivered.

## Hosting
Hosted with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/ (root)`).
